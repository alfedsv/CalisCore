1. ВВЕДЕНИЕ
Настоящая Политика конфиденциальности описывает, как CalisCore (далее — «Приложение») обрабатывает информацию пользователей.

Приложение разработано с уважением к вашей приватности. Я не собираю, не храню и не передаю какие-либо персональные данные.

2. КАКИЕ ДАННЫЕ Я НЕ СОБИРАЮ
Я не собираю следующие категории данных:

Персональные идентификаторы (имя, email, номер телефона, адрес)

Данные о местоположении

Контакты

Фотографии или медиафайлы

Данные о здоровье или фитнесе, передаваемые на серверы

Идентификаторы устройства для отслеживания

Данные об использовании приложения (аналитика, телеметрия)

3. ЛОКАЛЬНОЕ ХРАНЕНИЕ ДАННЫХ
Все данные, которые вы вводите в Приложение (например, настройки тренировок, история упражнений, предпочтения), хранятся исключительно локально на вашем устройстве. Эти данные не передаются на серверы, в облачные сервисы или третьим лицам.

При удалении Приложения все локальные данные безвозвратно удаляются.

4. ПЕРЕДАЧА ДАННЫХ ПО СЕТИ
Приложение не осуществляет передачу каких-либо данных по сети. Приложение работает полностью офлайн. Единственная сетевая активность связана с загрузкой обновлений через App Store, что регулируется политикой конфиденциальности Apple.

5. СТОРОННИЕ СЕРВИСЫ
Приложение не использует сторонние сервисы, которые собирают данные:

Аналитические сервисы (Google Analytics, Firebase и т.п.)

Рекламные сети и SDK

Сервисы отслеживания

Социальные плагины

6. ИНТЕГРАЦИЯ С APPLE HEALTHKIT
Если Приложение интегрировано с Apple HealthKit, данные о тренировках могут записываться в HealthKit только с вашего явного разрешения. Эти данные остаются на вашем устройстве и регулируются политикой конфиденциальности Apple. Приложение не считывает данные из HealthKit и не передаёт их третьим лицам.

7. КОНФИДЕНЦИАЛЬНОСТЬ ДЕТЕЙ
Приложение не собирает персональные данные от детей младше 13 лет. Поскольку Приложение не собирает никаких персональных данных, это требование соблюдается автоматически.
